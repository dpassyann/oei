# Bounded context: `profile` (ports)

Ports pour la lecture/mise à jour du profil professionnel et la publication du
profil public / carte numérique.

Endpoints OpenAPI correspondants : `GET|PUT /api/member/v1/profile`,
`GET /api/member/v1/public-profile`,
`POST /api/member/v1/public-profile/publish`,
`GET /api/public/v1/members/{publicSlug}`.
