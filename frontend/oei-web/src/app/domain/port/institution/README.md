# Bounded context: `institution` (ports)

Ports côté espace institutionnel connecté (compte, rôles, invitations,
affiliations, dashboard, publications, opportunités, propositions de badge,
audit) et côté page publique institutionnelle.

Endpoints OpenAPI correspondants : tout le préfixe `/api/institution/v1/**`, plus
`/api/public/v1/institutions/**` pour la vitrine publique.
