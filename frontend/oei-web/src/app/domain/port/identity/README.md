# Bounded context: `identity` (ports)

Ports `Observable`-returning pour l'inscription, la vérification d'identité et la
signature de la charte éthique.

Endpoints OpenAPI correspondants : `POST /api/public/v1/accounts`,
`POST /api/member/v1/ethical-charter/sign`,
`GET|POST /api/member/v1/verification-requests`.
