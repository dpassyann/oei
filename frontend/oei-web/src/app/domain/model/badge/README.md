# Bounded context: `badge`

Catalogue de badges (définitions) et attributions (`BadgeAward`) : source
(automatique, manuelle, proposition institutionnelle), dates, révocation,
historique.

Entités attendues : `Badge`, `BadgeAward`. L'OEI reste seul décideur pour
l'attribution d'un badge officiel (une proposition institutionnelle
(`institution.InstitutionBadgeProposal`) n'attribue jamais directement un badge).
