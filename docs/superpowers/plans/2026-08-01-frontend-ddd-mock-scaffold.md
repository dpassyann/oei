# Frontend DDD Mock Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a working Angular 22 frontend (`frontend/oei-web`), structured in DDD layers (domain/application/infrastructure/presentation), that renders the home page identically to the validated mockup (`.prompt/maquetteUI.png`) entirely from mock content by default, with a documented, config-only toggle to switch to a real backend API later — verified end-to-end by a Playwright smoke test running in mock mode with zero backend dependency.

**Architecture:** Standalone, zoneless Angular 22 app. `domain/` holds framework-free entities and port interfaces; `application/` holds `@Service`-annotated orchestration services returning DTOs; `infrastructure/` holds two adapter implementations per port (mock and real-API, the latter backed by an OpenAPI-generated client) plus a `RuntimeConfig` that resolves `dataSource: 'mock' | 'api'` at bootstrap; `presentation/` holds standalone components/pages that only ever depend on `application/` services. The active adapter is selected once, in `app.config.ts`, via `useFactory` keyed on `RuntimeConfig.dataSource()` — no branching inside application or presentation code.

**Tech Stack:** Angular 22, pnpm, TypeScript, `@angular/cdk` (a11y), `openapi-generator-cli` (`typescript-angular` generator), Playwright (`@playwright/test`).

## Global Constraints

- Package manager: **pnpm** everywhere (never npm/yarn) — `packageManager` field in `package.json`.
- Angular 22, standalone components only, **zoneless** change detection (`provideZonelessChangeDetection()`), OnPush is the implicit default — do not add `changeDetection: ChangeDetectionStrategy.OnPush` explicitly unless the installed Angular version still requires it (verify against `node_modules/@angular/core/package.json` version; if OnPush is not yet implicit in the installed version, add it explicitly and note the deviation).
- **API surface caution**: this plan specifies newer Angular 22 APIs (`@Service()` decorator, Signal Forms `@angular/forms/signals`, `resource`/`httpResource`, `injectAsync`, `provideAria()`) per the user's explicit direction. Before using any of these in a task, the implementer MUST verify the export actually exists in the installed `@angular/core`/`@angular/forms`/`@angular/cdk` packages (e.g. `grep` the package's `.d.ts` files, or try the import and read the compiler error). If an API does not exist in the installed version, fall back to its nearest stable equivalent (`@Injectable({ providedIn: 'root' })` instead of `@Service()`; `FormGroup`/`ReactiveFormsModule` instead of Signal Forms; a plain `signal()` + manual `fetch`/`HttpClient` call instead of `resource()`/`httpResource()`), and **document the fallback and why** in the task report. Never block a task on an unavailable preview API — always ship the working fallback.
- Every `@for` in a template MUST have `track` (compiler-enforced or not — always include it).
- Dev server port: **4300** (not 4200/4201/4202 — those are used by the unrelated `aegis` project's dashboard on this machine; verify with `lsof -iTCP -sTCP:LISTEN -n -P` before finalizing if in doubt).
- Palette: navy `#0a1e3f` / gold `#e8a530` (matches `.prompt/maquetteUI.png` and the Keycloak login theme from the infra plan).
- i18n: 6 languages active from day one (FR, EN, DE, ES, IT, PT) for interface strings; only FR and EN need real translated copy in this plan — DE/ES/IT/PT get the FR text as a placeholder value (not "TBD", actual French copy) so the switcher is functionally complete even before translation work lands.
- No real backend exists yet — the "api" adapter path must be implemented against a real, versioned OpenAPI contract (created in Task 5) so it is ready to work the moment a matching backend exists, but it is NOT expected to be exercised against a live server in this plan (mock mode is the only mode verified end-to-end here).

// frontend/oei-web/src/app/infrastructure/config/runtime-config.ts
import { Injectable, computed, signal } from '@angular/core';

export type DataSource = 'mock' | 'api';

export interface OeiRuntimeConfig {
  dataSource: DataSource;
  apiBaseUrl: string;
}

const STORAGE_KEY = 'oei-data-source';
const CONFIG_URL = '/config';

declare global {
  interface Window {
    __OEI_CONFIG__?: Partial<OeiRuntimeConfig>;
  }
}

@Injectable({ providedIn: 'root' })
export class RuntimeConfig {
  private readonly dataSourceSignal = signal<DataSource>(this.resolveDataSource());
  private readonly apiBaseUrlSignal = signal<string>(this.resolveApiBaseUrl());

  readonly dataSource = this.dataSourceSignal.asReadonly();
  readonly apiBaseUrl = this.apiBaseUrlSignal.asReadonly();
  readonly isMock = computed(() => this.dataSourceSignal() === 'mock');

  async load(): Promise<void> {
    try {
      const response = await fetch(CONFIG_URL, { headers: { Accept: 'application/json' } });
      if (!response.ok || !response.headers.get('content-type')?.includes('application/json')) {
        return;
      }
      const config = (await response.json()) as Partial<OeiRuntimeConfig>;
      if (typeof config.apiBaseUrl === 'string' && config.apiBaseUrl.length > 0) {
        this.apiBaseUrlSignal.set(config.apiBaseUrl);
      }
      if (!this.hasLocalOverride() && (config.dataSource === 'mock' || config.dataSource === 'api')) {
        this.dataSourceSignal.set(config.dataSource);
      }
    } catch {
      // Hors ligne / pas de serveur / réponse non JSON → on garde les valeurs par défaut.
    }
  }

  setDataSource(source: DataSource): void {
    this.dataSourceSignal.set(source);
    try {
      localStorage.setItem(STORAGE_KEY, source);
    } catch {
      // localStorage indisponible (mode privé, etc.) — pas bloquant.
    }
  }

  private hasLocalOverride(): boolean {
    try {
      return localStorage.getItem(STORAGE_KEY) !== null;
    } catch {
      return false;
    }
  }

  private resolveDataSource(): DataSource {
    try {
      const stored = localStorage.getItem(STORAGE_KEY);
      if (stored === 'mock' || stored === 'api') {
        return stored;
      }
    } catch {
      // ignore
    }
    const injected = typeof window !== 'undefined' ? window.__OEI_CONFIG__?.dataSource : undefined;
    return injected === 'api' ? 'api' : 'mock';
  }

  private resolveApiBaseUrl(): string {
    if (typeof window !== 'undefined' && window.__OEI_CONFIG__?.apiBaseUrl) {
      return window.__OEI_CONFIG__.apiBaseUrl;
    }
    return '/api/v1';
  }
}
```

// frontend/oei-web/src/app/infrastructure/adapter/i18n.service.ts
import { Injectable, signal } from '@angular/core';
import { SupportedLanguage } from '../../domain/model/document';

@Injectable({ providedIn: 'root' })
export class I18nService {
  private readonly cache = new Map<SupportedLanguage, Record<string, string>>();
  readonly currentLang = signal<SupportedLanguage>('fr');

  async setLang(lang: SupportedLanguage): Promise<void> {
    if (!this.cache.has(lang)) {
      const response = await fetch(`/i18n/${lang}.json`);
      this.cache.set(lang, await response.json());
    }
    this.currentLang.set(lang);
  }

  translate(key: string): string {
    const dict = this.cache.get(this.currentLang());
    return dict?.[key] ?? key;
  }
}
```
